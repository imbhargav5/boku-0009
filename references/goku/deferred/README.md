# Deferred references

These images were reviewed in labeled contact sheets and intentionally moved out of the first-pass training set because they are lower priority, effect-heavy, child/chibi, multi-subject, crossover, text-heavy, ambiguous, or near-duplicates.

They are preserved for later experiments. See `data/deferred-manifest.jsonl` for the reason recorded for each move. The curated first-pass set is described by `data/reference-manifest.jsonl`.
